# E0329: Trait cannot be derived for this type

You used `@[derive(...)]` with a trait that cannot be automatically derived for the target type.

Deriving built-in traits like `Copy` or `Clone` requires all fields of the struct or enum to also implement those traits.

## Example

```loom
struct NonCopy
  x: String
end

@[derive(Copy)]
struct Container
  field: NonCopy
end

def main
end
```

## How to fix it

Ensure all fields implement the derived trait, or manually implement the trait.

```loom
@[derive(Copy)]
struct Container
  field: Int
end

def main
end
```

See spec §6.7.
