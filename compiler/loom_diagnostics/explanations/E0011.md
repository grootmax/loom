# E0011: Decimal literal with a leading zero

You wrote a decimal integer literal with a leading zero followed by other digits, such as `012`.

Loom forbids leading zeros on decimal numbers to avoid ambiguity with C-style octal literals. Octal literals in Loom require an explicit `0o` prefix.

## Example

```loom
def main
  x = 012
end
```

## How to fix it

Remove the leading zero for a decimal number, or use `0o` for octal.

```loom
def main
  x = 12
end
```

See spec §2.7.1.
