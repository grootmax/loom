# E0200: Unresolved name

You referenced a variable, function, or type name that has not been defined or imported into the current scope.

Loom requires all identifiers to be explicitly declared or imported before they are used.

## Example

```loom
def main
  puts x
end
```

## How to fix it

Declare the variable or import the item before using it.

```loom
def main
  x = 42
  puts x
end
```

See spec §12.2.
