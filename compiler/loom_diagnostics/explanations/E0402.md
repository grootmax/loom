# E0402: Or-pattern alternatives bind different names

You wrote an or-pattern `A | B` where the alternatives bind different variable names or different numbers of variables.

All alternatives in an or-pattern must bind the exact same set of names with the same types so that the variables are consistently available in the match body.

## Example

```loom
def main
  val = Option.Some(42)
  case val
    in Some(x) | None
      puts(1)
  end
end
```

## How to fix it

Ensure all alternatives bind the same names, or use wildcards `_` if variable values are not needed.

```loom
def main
  val = Option.Some(42)
  case val
    in Some(_) | None
      puts(1)
  end
end
```

See spec §9.1.
