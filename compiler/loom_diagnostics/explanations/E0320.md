# E0320: Trait bound not satisfied

You passed a type to a generic function or structure that does not satisfy the required trait bounds.

Generic parameters with trait bounds (such as `T: Display`) require concrete types that implement the specified traits.

## Example

```loom
struct Custom
end

def print_it[T: Display](val: T)
  puts(val)
end

def main
  c = Custom()
  print_it(c)
end
```

## How to fix it

Implement the required trait for the type before passing it to the generic function.

```loom
struct Custom
end

impl Display for Custom
  def to_string -> String = "Custom"
end

def print_it[T: Display](val: T)
  puts(val)
end

def main
  c = Custom()
  print_it(c)
end
```

See spec §6.6.
