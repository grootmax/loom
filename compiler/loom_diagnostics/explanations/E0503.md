# E0503: Borrow escapes: stored, moved to `own`, or captured by an escaping closure

You attempted to return or store a reference beyond the lifetime of its borrowed source.

A reference cannot escape the function where the borrowed variable is defined. Returning a reference to a local variable creates a dangling reference once the function finishes and drops its local variables.

## Example

```loom
def bad_borrow -> ref String
  var s = "hello"
  s
end

def main
end
```

## How to fix it

Return an owned value instead of a reference to a local variable.

```loom
def good_borrow -> String
  var s = "hello"
  s
end

def main
end
```

See spec §8.3.
