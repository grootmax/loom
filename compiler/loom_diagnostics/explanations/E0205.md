# E0205: Item, field or method is not visible here

You attempted to access a module item, field, or method that is private to another module or type.

In Loom, items are private by default unless marked with `pub`. Private items cannot be accessed outside their defining module.

## Example

```loom
module secret
  def hidden
    1
  end
end

use secret.hidden

def main
end
```

## How to fix it

Mark the item with `pub` to make it accessible to other modules.

```loom
module secret
  pub def hidden
    1
  end
end

use secret.hidden

def main
end
```

See spec §3.11.
