# E0026: Unterminated raw string

A raw string literal `r"…"` or `r#"…"#` reached the end of the file without finding a matching closing delimiter.

Raw string literals end only when encountering a double quote followed by the exact number of `#` characters present in the opening delimiter.

## Example

```loom
def main()
  s = r#"hello
```

## How to fix it

Close the raw string with a double quote followed by the matching number of `#` characters.

```loom
def main()
  s = r#"hello"#
end
```

See spec §2.7.4.
