# E0103: Unexpected closing delimiter or `end`

The parser encountered a closing delimiter `)`, `]`, `}` or keyword `end` where no matching opening construct was active.

This occurs when there is an extra closing symbol or a missing opening construct earlier in the file.

## Example

```loom
def main()
  puts "hello"
end
end
```

## How to fix it

Remove the extra closing delimiter or `end` keyword.

```loom
def main()
  puts "hello"
end
```

See spec §3, §7.
