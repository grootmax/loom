# E0304: Unknown field

You accessed a field name that does not exist on the type.

Struct field accesses must refer to fields declared in the struct's definition.

## Example

```loom
struct Point
  x: Int
end

def main
  p = Point(x: 1)
  puts(p.y)
end
```

## How to fix it

Access a field that exists on the struct.

```loom
struct Point
  x: Int
end

def main
  p = Point(x: 1)
  puts(p.x)
end
```

See spec §3.2.
