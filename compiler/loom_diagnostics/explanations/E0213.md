# E0213: Unknown attribute

You applied an attribute that is not recognized by the Loom compiler.

Only compiler-supported attributes (such as `@intrinsic`, `@derive`, `@inline`) may be used.

## Example

```loom
@[unknown_attribute]
def helper
  1
end

def main
end
```

## How to fix it

Remove the unknown attribute or replace it with a valid attribute.

```loom
def helper
  1
end

def main
end
```

See spec §3.10.
