# E0013: Uppercase radix prefix

You used an uppercase radix prefix like `0X`, `0O`, or `0B` in a numeric literal.

Loom requires all numeric radix prefixes to be lowercase (`0x` for hex, `0o` for octal, `0b` for binary) to maintain consistent syntax styling across codebases.

## Example

```loom
def main
  x = 0XFF
end
```

## How to fix it

Use a lowercase radix prefix (`0x`, `0o`, or `0b`).

```loom
def main
  x = 0xff
end
```

See spec §2.7.1.
