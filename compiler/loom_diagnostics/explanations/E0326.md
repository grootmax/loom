# E0326: Conflicting implementations

You wrote two `impl Trait for Type` blocks for the same trait and type in the same program.

A trait can only be implemented once for any given type to avoid conflicting method definitions.

## Example

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
end

impl Speak for Dog
  def speak -> String = "bark"
end

def main
end
```

## How to fix it

Remove the duplicate `impl` block or combine its definitions into a single implementation.

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
end

def main
end
```

See spec §3.5.
