# E0007: `!` is not an operator

You used `!` as a unary boolean negation operator. In Loom, `!` is not an operator.

Loom uses the keyword `not` for boolean negation (and `~` for bitwise complement). `not` reads naturally like English, avoids visual confusion with inequality (`!=`), and binds looser than comparison operators (`not a == b` means `not (a == b)`).

## Example

```loom
def main()
  if !true
    puts "false"
  end
end
```

## How to fix it

Use `not` instead of `!`.

```loom
def main()
  if not true
    puts "false"
  end
end
```

See spec §2.8.3.

Coming from Rust/C/Ruby: Use `not` for logical negation and `~` for bitwise complement.
