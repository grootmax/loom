# E0025: Line in a triple-quoted string lacks the indentation prefix

A non-blank line in a multiline string literal has less leading whitespace than the closing `"""` line.

The whitespace preceding the closing `"""` sets the indentation prefix stripped from every line of content. All non-blank content lines must begin with at least this indentation prefix.

## Example

```loom
def main
  s = """
hello
    """
end
```

## How to fix it

Indent all content lines to match or exceed the indentation of the closing `"""`.

```loom
def main
  s = """
    hello
    """
end
```

See spec §2.7.4.
