# E0500: Use of a moved value

You attempted to use a variable or value after its ownership was moved to another variable or function call.

In Loom, types that do not implement `Copy` transfer ownership when assigned or passed by value. Once moved, the original binding cannot be read or used again.

## Example

```loom
def main
  s = "hello"
  a = s
  b = s
end
```

## How to fix it

Avoid using values after they are moved, or pass references/copies instead.

```loom
def main
  s = "hello"
  a = s
end
```

See spec §8.1.
