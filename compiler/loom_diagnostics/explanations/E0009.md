# E0009: Reserved word used as an identifier

You used a reserved word (such as `async`, `await`, `try`, or `yield`) as an identifier name.

Loom reserves specific words for future language features. Reserving these words prevents syntax conflicts and guarantees backwards compatibility when those features are eventually introduced.

## Example

```loom
def main
  async = 10
end
```

## How to fix it

Choose a different identifier name that is not a reserved word.

```loom
def main
  is_async = 10
end
```

See spec §2.6.
