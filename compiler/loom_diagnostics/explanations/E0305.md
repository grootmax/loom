# E0305: Missing or repeated field in a construction

You instantiated a struct while omitting a required field or specifying the same field more than once.

Struct construction requires every field declared in the struct definition to be provided exactly once.

## Example

```loom
struct Point
  x: Int
  y: Int
end

def main
  p = Point(x: 1)
end
```

## How to fix it

Provide all required fields in the struct construction.

```loom
struct Point
  x: Int
  y: Int
end

def main
  p = Point(x: 1, y: 2)
end
```

See spec §3.2.
