# E0401: Refutable pattern where an irrefutable one is required

You used a refutable pattern (a pattern that might fail to match) in a context that requires an irrefutable pattern, such as a `for` loop binding.

Loop bindings expect patterns that match all values of the type. Refutable patterns like enum variants must be tested using `if ... in ...` or `case`.

## Example

```loom
def main
  items = [Option.Some(1)]
  for Some(x) in items
    puts(x)
  end
end
```

## How to fix it

Use an `if ... in ...` condition or `case` expression to match refutable patterns.

```loom
def main
  val = Option.Some(1)
  if val in Some(x)
    puts(x)
  end
end
```

See spec §9.2.
