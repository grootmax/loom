# E0017: Unterminated character literal

A character literal started with a single quote `'` but was not closed before reaching a line terminator or end of file.

Character literals cannot span across lines and must be closed with a matching single quote on the same line.

## Example

```loom
def main
  c = 'a
end
```

## How to fix it

Add a closing single quote on the same line.

```loom
def main
  c = 'a'
end
```

See spec §2.7.3.
