# E0400: Non-exhaustive `case`

You wrote a `case` expression that does not cover all possible variants or values of the matched type.

Pattern matching in Loom must be exhaustive: every possible value of the matched expression must be handled by at least one arm or an `else` / wildcard `_` arm.

## Example

```loom
def main
  val = Option.Some(42)
  case val
    in Some(x)
      puts(x)
  end
end
```

## How to fix it

Add arms for missing variants or add an `else` arm.

```loom
def main
  val = Option.Some(42)
  case val
    in Some(x)
      puts(x)
    in None
      puts(0)
  end
end
```

See spec §9.4.
