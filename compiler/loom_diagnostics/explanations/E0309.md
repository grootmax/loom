# E0309: Type cannot be indexed

You used index syntax `[i]` on a type that does not support indexing.

Indexing expressions are only supported on types like `Array` or custom types implementing index operations.

## Example

```loom
def main
  x: Int = 42
  puts(x[0])
end
```

## How to fix it

Use index syntax only on indexable collection types such as `Array`.

```loom
def main
  x = [1, 2, 3]
  puts(x[0])
end
```

See spec §7.4.
