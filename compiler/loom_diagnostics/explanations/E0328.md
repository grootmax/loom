# E0328: Trait is not object-safe

You attempted to construct a trait object `dyn Trait` for a trait that is not object-safe.

Traits used as trait objects (`dyn Trait`) cannot contain generic methods or methods that return `Self`.

## Example

```loom
trait TraitWithGeneric
  def make[T](x: T)
end

def call_dyn(obj: dyn TraitWithGeneric)
end

def main
end
```

## How to fix it

Use dynamic trait objects only with traits whose methods are object-safe.

```loom
trait ObjectSafe
  def act
end

def call_dyn(obj: dyn ObjectSafe)
end

def main
end
```

See spec §5.5.
