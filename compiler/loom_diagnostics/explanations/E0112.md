# E0112: Nesting too deep

Your code exceeds the maximum allowed syntax nesting depth (256 levels).

Loom limits expression, block, and delimiter nesting to a maximum depth of 256 levels to prevent stack overflow or memory exhaustion during parsing.

## Example

```loom
def main()
  # Expression or block nested deeper than 256 levels
  ((((((1))))))
end
```

## How to fix it

Refactor deeply nested code into smaller helper functions or flatter expressions.

```loom
def main()
  x = 1
end
```

See implementation limits.
