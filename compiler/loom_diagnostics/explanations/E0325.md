# E0325: Expected a trait

You used a type name where a trait was expected in an `impl Trait for Type` block.

In `impl Trait for Type`, the target before `for` must be a valid trait definition, not a struct or enum type.

## Example

```loom
struct Point
  x: Int
end

struct Foo
end

impl Point for Foo
end

def main
end
```

## How to fix it

Specify a trait name before `for` in the implementation block.

```loom
trait Named
  def name -> String
end

struct Foo
end

impl Named for Foo
  def name -> String = "Foo"
end

def main
end
```

See spec §3.5.
