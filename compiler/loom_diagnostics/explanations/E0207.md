# E0207: `self` or `@field` outside a method

You used `self` or field access syntax `@field` in a context outside an instance method.

In Loom, `@field` shorthand and `self` references are only valid inside method bodies defined on a `struct` or `enum`. Top-level functions do not have a receiver instance.

## Example

```loom
def main
  puts(@x)
end
```

## How to fix it

Access fields inside a method or pass values as function parameters.

```loom
struct Point
  x: Int

  def print_x
    puts(@x)
  end
end

def main
  p = Point(x: 10)
  p.print_x()
end
```

See spec §3.1.
