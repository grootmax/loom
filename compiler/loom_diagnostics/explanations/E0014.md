# E0014: Invalid suffix on a numeric literal

You attached a type suffix (such as `i32` or `f64`) to a numeric literal.

Loom numeric literals do not accept type suffixes. Type inference determines the literal's type from context, defaulting to `Int` for integers and `Float` for floating-point values.

## Example

```loom
def main
  x = 42i32
end
```

## How to fix it

Remove the type suffix from the literal.

```loom
def main
  x = 42
end
```

See spec §2.7.1.
