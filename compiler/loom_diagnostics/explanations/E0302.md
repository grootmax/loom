# E0302: `ref` type outside a function's return type

You used a `ref` reference type annotation outside of a function's return type declaration.

In Loom, reference types like `ref T` are only permitted in function return signatures to return borrowed references to data. Variable bindings and fields cannot store `ref` types directly.

## Example

```loom
def main
  x: ref Int = 42
end
```

## How to fix it

Use an owned type for variable annotations or fields.

```loom
def main
  x: Int = 42
end
```

See spec §5.6.
