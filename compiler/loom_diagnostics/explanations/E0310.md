# E0310: Literal out of range for its type

You specified a numeric literal value that exceeds the minimum or maximum bounds of its target numeric type.

Numeric types have fixed bit-widths and valid value ranges. For example, `U8` accepts integers only from 0 through 255.

## Example

```loom
def main
  x: U8 = 300
end
```

## How to fix it

Use a literal value within the valid range of the type, or use a larger integer type.

```loom
def main
  x: U8 = 200
end
```

See spec §6.2.
