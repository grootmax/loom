# E0106: Assignment is only allowed as a statement (`if x = 1`)

You used an assignment `=` inside an expression context, such as an `if` condition.

In Loom, assignment `=` is a statement and does not yield a value. This prevents accidental assignment bugs when equality comparison `==` was intended.

## Example

```loom
def main()
  var x = 0
  if x = 1
    puts "yes"
  end
end
```

## How to fix it

Use the equality operator `==` for comparisons inside expressions.

```loom
def main()
  var x = 0
  if x == 1
    puts "yes"
  end
end
```

See spec §4.2, §7.5.
