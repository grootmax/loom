# E0504: `ref` return type without an elided source

You declared a function with a `ref` return type but provided no parameter or receiver with a reference from which the returned borrow can originate.

Every returned reference (`ref T`) must originate from a borrowed parameter or method receiver (`self`).

## Example

```loom
def get_val -> ref Int
  42
end

def main
end
```

## How to fix it

Return references from method receivers or return owned values.

```loom
struct Point
  x: Int

  def get_x -> ref Int = @x
end

def main
end
```

See spec §8.3.
