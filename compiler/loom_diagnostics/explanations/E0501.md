# E0501: Move out of a borrowed place

You attempted to move a value out of a borrowed place or collection element.

Values behind references or inside collection elements are owned elsewhere and cannot be moved out directly.

## Example

```loom
def take(own s: String)
end

def test(s: String)
  take(s)
end

def main
end
```

## How to fix it

Clone the value or operate on it through references without moving it out of the collection.

```loom
def take(s: String)
end

def test(s: String)
  take(s)
end

def main
end
```

See spec §8.1.
