# E0307: Unknown or repeated named argument

You passed a named argument that does not match any parameter name of the function, or repeated the same named argument.

Named arguments in function calls must correspond to valid parameter names defined on the function signature and must not be repeated.

## Example

```loom
def add(x: Int) -> Int
  x
end

def main
  add(y: 1)
end
```

## How to fix it

Use the parameter name declared in the function's definition.

```loom
def add(x: Int) -> Int
  x
end

def main
  add(x: 1)
end
```

See spec §3.1.
