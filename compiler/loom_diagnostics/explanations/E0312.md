# E0312: Cannot mutate an immutable place

You attempted to modify a field or variable that is immutable.

To mutate fields inside a method, the method signature must be declared with `def mut`. To mutate a variable binding, the variable must be declared with `var`.

## Example

```loom
struct Point
  x: Int

  def reset
    @x = 0
  end
end

def main
end
```

## How to fix it

Mark the method with `mut` if it mutates receiver fields.

```loom
struct Point
  x: Int

  def mut reset
    @x = 0
  end
end

def main
end
```

See spec §4.2.
