# E0101: Unclosed delimiter `(`, `[`, `{` or `#{`

An opening parenthesis `(`, bracket `[`, brace `{`, or string interpolation sequence `#{` was not closed by a matching closing delimiter.

Every opening delimiter must be balanced by a matching closing delimiter `)`, `]`, or `}` in the same scope.

## Example

```loom
def main()
  x = (1 + 2
end
```

## How to fix it

Add the matching closing delimiter.

```loom
def main()
  x = (1 + 2)
end
```

See spec §2.3.
