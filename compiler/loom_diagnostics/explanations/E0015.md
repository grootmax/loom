# E0015: Empty character literal

You wrote an empty character literal `''`.

Character literals in Loom are delimited by single quotes and must enclose exactly one Unicode scalar value or valid escape sequence.

## Example

```loom
def main()
  c = ''
end
```

## How to fix it

Provide a character inside the single quotes.

```loom
def main()
  c = 'a'
end
```

See spec §2.7.3.
