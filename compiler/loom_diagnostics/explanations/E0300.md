# E0300: Mismatched types

You used an expression whose type does not match the expected type in this context.

Loom is statically typed and requires all expressions, assignments, and function parameters to have compatible types.

## Example

```loom
def main
  x: Int = "hello"
end
```

## How to fix it

Provide a value matching the expected type.

```loom
def main
  x: Int = 42
end
```

See spec §6.4.
