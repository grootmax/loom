# E0204: Pattern test binds names outside a condition

You used a pattern test expression `expr in Pattern` that binds new variable names outside an `if` or `while` condition.

In Loom, pattern tests that introduce new variable bindings (such as `val in Some(x)`) are only valid in conditional statements (`if` or `while`) where the binding's scope is strictly bounded. Outside a condition, use `case` matching or wildcard patterns.

## Example

```loom
def main
  val = Option.Some(42)
  val in Option.Some(x)
end
```

## How to fix it

Use an `if` condition to test the pattern and bind the name.

```loom
def main
  val = Option.Some(42)
  if val in Option.Some(x)
    puts(x)
  end
end
```

See spec §9.3.
