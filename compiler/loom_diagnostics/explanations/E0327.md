# E0327: Implementation violates the orphan rule

You implemented a external trait for a foreign type when neither the trait nor the type was defined in the current crate.

The orphan rule ensures coherence by requiring that either the trait or the implementing type must be local to the module/package defining the implementation.

## Example

```loom
impl Display for Int
  def to_string -> String = "42"
end

def main
end
```

## How to fix it

Implement local traits for external types, or implement external traits for local types.

```loom
struct MyInt
  value: Int
end

impl Display for MyInt
  def to_string -> String = "MyInt"
end

def main
end
```

See spec §3.5.
