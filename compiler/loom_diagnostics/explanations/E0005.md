# E0005: Unexpected character

The lexer encountered a character that cannot begin or form any valid token in Loom.

This happens when source code contains unexpected symbols (such as backticks `` ` `` or dollar signs `$`) outside of string literals or comments.

## Example

```loom
def main()
  `invalid`
end
```

## How to fix it

Remove the invalid character or replace it with valid Loom syntax.

```loom
def main()
  "valid"
end
```

See spec §2.

Coming from Ruby/Rust: Backticks are not used for command execution or lifetimes in Loom.
