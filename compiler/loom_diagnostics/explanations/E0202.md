# E0202: Name declared twice in one namespace

You declared two items with the same name in the same module namespace.

Top-level declarations within a module must have unique names to avoid ambiguity.

## Example

```loom
def helper
  1
end

def helper
  2
end

def main
  puts helper()
end
```

## How to fix it

Rename one of the items or remove the duplicate definition.

```loom
def helper_one
  1
end

def helper_two
  2
end

def main
  puts helper_one()
end
```

See spec §12.1.
