# E0321: Missing item in an implementation

Your `impl Trait for Type` block omitted one or more items required by the trait definition.

A trait implementation must define all non-default methods, types, and constants declared in the trait.

## Example

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
end

def main
end
```

## How to fix it

Provide definitions for all required items in the `impl` block.

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
end

def main
end
```

See spec §3.5.
