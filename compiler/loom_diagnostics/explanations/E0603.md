# E0603: A `select` arm is not a channel operation or timer

Each arm of `select` waits on `ch.recv`, `ch.send(value)` or `Time.after(duration)` (spec §11.3). Only a `recv` arm can receive into a pattern.

## Example

```loom
def main
  inbox = Chan[Int].new(capacity: 1)
  select
  when inbox.length then puts "?"
  end
end
```

## How to fix it

```loom
use std.time.{Time, DurationLiterals}

def main
  inbox = Chan[Int].new(capacity: 1)
  select
  when Some(n) = inbox.recv then puts n
  when Time.after(10.milliseconds) then puts "timed out"
  end
end
```
