# E0108: Inner doc comment (`##!`) after an item

An inner doc comment (`##!`) appears after item declarations in a module or file.

Inner doc comments (`##!`) document the enclosing module itself and must appear at the top of the file before any item declarations (`def`, `struct`, `const`, etc.). Outer doc comments (`##`) document individual items.

## Example

```loom
def main
  puts "hello"
end

##! Module documentation comment
```

## How to fix it

Move inner doc comments (`##!`) to the top of the file before any items, or use outer doc comments (`##`) to document items.

```loom
##! Module documentation comment

def main
  puts "hello"
end
```

See spec §2.4.
