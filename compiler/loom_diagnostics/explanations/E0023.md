# E0023: Opening `"""` not followed by a line break

You wrote content on the same line immediately following the opening triple quotes `"""`.

In Loom multiline string literals, the opening delimiter `"""` must be followed immediately by a line break. Content lines begin on the next line.

## Example

```loom
def main
  s = """hello
  world
  """
end
```

## How to fix it

Insert a line break immediately after the opening `"""`.

```loom
def main
  s = """
  hello
  world
  """
end
```

See spec §2.7.4.
