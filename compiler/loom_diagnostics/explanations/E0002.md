# E0002: Bidirectional formatting character

Loom source code contains a Unicode bidirectional (bidi) formatting control character (such as U+202A–U+202E or U+2066–U+2069).

This restriction protects against "Trojan Source" security attacks, where hidden bidirectional control characters alter the visual display order of code so that humans see one program while the compiler executes another. If you need bidirectional formatting characters inside string literals, use `\u{…}` escape sequences instead.

## Example

```loom
# Contains invisible ‮ bidirectional override character
def main
  x = 1
end
```

## How to fix it

Remove the hidden bidirectional formatting character from your source code, or write it as a Unicode escape inside a string literal.

```loom
def main
  x = "\u{202E}text"
end
```

See spec §2.1.4.
