# E0323: Item is not a member of the trait

You declared an item inside `impl Trait for Type` that is not part of the trait definition.

An `impl Trait for Type` block can only contain items (methods, types, constants) declared in `Trait`.

## Example

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
  def bark
  end
end

def main
end
```

## How to fix it

Remove extra items from the `impl` block or declare them directly in the struct body as inherent methods.

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
end

def main
end
```

See spec §3.5.
