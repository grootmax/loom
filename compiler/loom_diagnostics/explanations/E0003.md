# E0003: Carriage return not followed by line feed

The source file contains a bare carriage return character (`\r`, U+000D) that is not immediately followed by a line feed character (`\n`, U+000A).

Loom normalizes line endings to Unix-style line feeds (`\n`) or Windows-style CRLF pairs (`\r\n`). Bare carriage returns are forbidden to ensure consistent line break semantics and line counts across operating systems.

## Example

```loom
def main  puts "hello"end
```

## How to fix it

Configure your editor to use standard line endings (LF or CRLF).

```loom
def main
  puts "hello"
end
```

See spec §2.2.1.
