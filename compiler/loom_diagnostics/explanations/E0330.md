# E0330: Unknown associated item

You accessed an associated item (constant, type, or function) that does not exist on the specified type.

Associated item access `Type.ITEM` requires that `ITEM` is declared within the type's body or an implemented trait.

## Example

```loom
struct Point
  x: Int
end

def main
  x = Point.UNKNOWN_CONST
end
```

## How to fix it

Access an associated item that is defined on the type.

```loom
struct Point
  x: Int
  const ZERO: Int = 0
end

def main
  x = Point.ZERO
end
```

See spec §7.2.
