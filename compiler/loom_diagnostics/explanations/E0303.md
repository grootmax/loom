# E0303: Wrong number of generic arguments

You supplied a different number of generic type arguments than a generic type or path expects.

When using generic types, you must provide the exact number of type parameters declared by that type.

## Example

```loom
def main
  x: Option[Int, String] = Option.None
end
```

## How to fix it

Provide the expected number of generic type arguments.

```loom
def main
  x: Option[Int] = Option.None
end
```

See spec §5.2.
