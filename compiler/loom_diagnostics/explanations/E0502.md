# E0502: Conflicting borrow, or use of a borrowed place

You attempted to mutate or reborrow a variable while an active reference to it already exists.

To guarantee memory safety and data-race freedom, Loom prohibits mutating or reborrowing a place while it is borrowed elsewhere.

## Example

```loom
def borrow_it(s: String) -> ref String = s

def main
  var s = "hello"
  r = borrow_it(s)
  s = "world"
  puts(r)
end
```

## How to fix it

Finish using the reference before mutating the borrowed variable, or operate on owned values.

```loom
def main
  var s = "hello"
  puts(s)
  s = "world"
end
```

See spec §8.2.
