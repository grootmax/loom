# E0102: Missing `end`

A block structure (such as `def`, `struct`, `enum`, `trait`, `impl`, `if`, `while`, `for`, `loop`, `case`, `select`, or `module`) reached the end of the file or enclosing scope without a closing `end` keyword.

Loom uses the keyword `end` to terminate item definitions and multi-line block bodies.

## Example

```loom
def main
  puts "hello"
```

## How to fix it

Add `end` to close the block structure.

```loom
def main
  puts "hello"
end
```

See spec §3, §7.
