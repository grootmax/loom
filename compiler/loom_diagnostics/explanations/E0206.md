# E0206: Unresolved import

You tried to import an item or module that does not exist or cannot be resolved.

Import paths must specify valid, accessible modules and exported items within the current package or standard library.

## Example

```loom
use core.io.non_existent_function

def main
end
```

## How to fix it

Specify a valid module path and item name in the `use` declaration.

```loom
use core.io.puts

def main
end
```

See spec §3.7.
