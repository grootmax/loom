# E0322: Ambiguous method

You invoked a method name that is provided by multiple implemented traits for the type, causing ambiguity.

When multiple implemented traits define methods with identical names, use fully-qualified call syntax to clarify which trait's method to call.

## Example

```loom
trait A
  def do_it
end

trait B
  def do_it
end

struct Foo
end

impl A for Foo
  def do_it
  end
end

impl B for Foo
  def do_it
  end
end

def main
  f = Foo()
  f.do_it()
end
```

## How to fix it

Use fully qualified syntax specifying the trait name.

```loom
trait A
  def do_it
end

trait B
  def do_it
end

struct Foo
end

impl A for Foo
  def do_it
  end
end

impl B for Foo
  def do_it
  end
end

def main
  f = Foo()
  A.do_it()
end
```

See spec §7.4.
