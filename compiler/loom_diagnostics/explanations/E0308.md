# E0308: Value is not callable

You attempted to invoke a value as a function when its type is not a callable function, method, or closure.

Only values whose types are function pointers or closures can be invoked with call syntax `()`.

## Example

```loom
def main
  x: Int = 42
  x()
end
```

## How to fix it

Only call values that are functions or closures.

```loom
def helper -> Int
  42
end

def main
  helper()
end
```

See spec §7.3.
