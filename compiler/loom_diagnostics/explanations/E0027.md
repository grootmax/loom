# E0027: `#![` at the start of a file is reserved

Your file starts with `#![`, which is reserved by Loom.

While shebang lines starting with `#!` are allowed on the first line and ignored by the compiler, `#![` is reserved for future file-level inner attribute syntax.

## Example

```loom
#![bin]
def main
  puts "hello"
end
```

## How to fix it

Remove `#![` from the start of the file or use item attributes `@[attr]` instead.

```loom
#!/usr/bin/env loom
def main
  puts "hello"
end
```

See spec §2.1.3.
