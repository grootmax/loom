# E0100: Expected a different token (general syntax error)

The parser encountered a token that does not form a valid statement, expression, or item declaration according to Loom grammar rules.

This general syntax error occurs when tokens appear in an unexpected sequence or structure.

## Example

```loom
def main
  if
end
```

## How to fix it

Supply the missing expression or token expected by the grammar construct.

```loom
def main
  if true
    puts "hello"
  end
end
```

See grammar.
