# E0001: Source file is not valid UTF-8

Loom source files must be text encoded in valid UTF-8. The compiler encountered one or more byte sequences that cannot be decoded as valid UTF-8.

This rule ensures that source code can be consistently parsed, edited, and rendered across all standard development tools and platforms without encoding ambiguities.

## Example

```loom
# Source file containing invalid raw byte sequence (e.g. 0xFF)
def main
  puts "hello"
end
```

## How to fix it

Re-save your source file using UTF-8 text encoding in your text editor or IDE.

```loom
def main
  puts "hello"
end
```

See spec §2.1.1.
