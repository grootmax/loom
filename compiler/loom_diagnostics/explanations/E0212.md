# E0212: Intrinsic declared outside the core library, or unknown intrinsic

You declared an `@intrinsic` attribute outside the core standard library, or specified an unrecognized intrinsic name.

Compiler intrinsics are low-level built-in primitives that can only be defined within Loom's core library.

## Example

```loom
extern "intrinsic"
  def custom_fn
end

def main
end
```

## How to fix it

Remove the `@intrinsic` attribute and implement the function using regular Loom code.

```loom
def custom_fn
  42
end

def main
end
```

See spec §13.
