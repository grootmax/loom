# E0012: Invalid or missing digits in a numeric literal

A numeric literal is missing required digits or contains invalid digits for its radix or format.

Radix prefixes (`0x`, `0o`, `0b`) must be followed by at least one valid digit for that base. Float literals must also have digits on both sides of the decimal point (e.g., `0.5` instead of `.5`).

## Example

```loom
def main()
  x = 0x
end
```

## How to fix it

Provide valid digits for the numeric literal.

```loom
def main()
  x = 0xff
end
```

See spec §2.7.1, §2.7.2.
