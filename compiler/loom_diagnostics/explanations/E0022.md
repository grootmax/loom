# E0022: Non-ASCII character in a byte string

You placed a raw non-ASCII character in a byte string literal `b"…"`.

Byte strings (`b"…"`) represent sequences of raw byte values and may contain only ASCII characters (code points U+0000 to U+007F) or hexadecimal byte escapes `\xHH`.

## Example

```loom
def main()
  b = b"hello \u{1F600}"
end
```

## How to fix it

Use `\xHH` byte escapes for non-ASCII byte values or use standard string literals `"..."`.

```loom
def main()
  b = b"hello \x00"
end
```

See spec §2.7.4.
