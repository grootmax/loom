# E0306: No method with this name for this type

You called a method name that is not implemented for the target value's type.

Method calls require that the target type or an implemented trait defines a method with that name.

## Example

```loom
def main
  1.non_existent_method()
end
```

## How to fix it

Call a method that is defined for the type or implement a trait providing the method.

```loom
def main
  puts(1.to_string)
end
```

See spec §7.4.
