# E0020: Invalid `\u{…}` escape

You wrote a Unicode escape sequence `\u{…}` that contains invalid hexadecimal digits, has no digits, or specifies an invalid scalar value (surrogate code points 0xD800–0xDFFF or values above U+10FFFF).

Unicode escape sequences must contain 1 to 6 hexadecimal digits specifying a valid Unicode scalar value.

## Example

```loom
def main
  s = "\u{D800}"
end
```

## How to fix it

Provide a valid Unicode scalar value inside `\u{…}`.

```loom
def main
  s = "\u{1F600}"
end
```

See spec §2.7.5.
