# E0016: Character literal with more than one character

You wrote a single-quoted literal containing multiple characters, like `'abc'`.

Single quotes in Loom define a single `Char` value. Text containing multiple characters must be enclosed in double quotes (`"abc"`) to form a `String`.

## Example

```loom
def main()
  s = 'hello'
end
```

## How to fix it

Use double quotes for string literals.

```loom
def main()
  s = "hello"
end
```

See spec §2.7.3.

Coming from Ruby: Single quotes define single `Char` literals in Loom, not string literals. Use double quotes for strings.
