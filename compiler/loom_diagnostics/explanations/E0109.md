# E0109: `impl` without a trait; inherent methods belong in the type's body

You wrote an `impl Type` block without specifying a trait to define inherent methods.

In Loom, inherent methods are written directly inside the `struct` or `enum` definition body rather than in separate `impl` blocks (ADR 0003). This keeps a type's fields and methods consolidated in one place. `impl` blocks are reserved exclusively for trait implementations (`impl Trait for Type`).

## Example

```loom
struct Point
  x: Int
  y: Int
end

impl Point
  def reset()
    @x = 0
  end
end
```

## How to fix it

Place inherent method definitions directly inside the type's body.

```loom
struct Point
  x: Int
  y: Int

  def reset()
    @x = 0
  end
end
```

See spec §3.5.

Coming from Rust: Do not write `impl Type`. Inherent methods are defined directly inside `struct` or `enum` bodies.
