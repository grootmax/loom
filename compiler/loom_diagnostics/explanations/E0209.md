# E0209: Name of the wrong kind (a type where a value is expected, or the reverse)

You used a type name where an expression value was expected, or used a value name where a type was expected.

Loom distinguishes between value identifiers and type identifiers. Types cannot be evaluated directly as values, and variable values cannot be used in type annotations.

## Example

```loom
def main
  x = Int
end
```

## How to fix it

Use a value expression rather than a type name.

```loom
def main
  x = 42
end
```

See spec §12.2.
