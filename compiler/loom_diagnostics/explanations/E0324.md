# E0324: Method does not match the trait's declaration

You implemented a trait method with parameters or a return type that differs from the trait's declaration.

Methods in `impl Trait for Type` must match the parameter types, parameter counts, and return type declared in `Trait`.

## Example

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak(volume: Int) -> String = "woof"
end

def main
end
```

## How to fix it

Update the method signature in the implementation to match the trait declaration.

```loom
trait Speak
  def speak -> String
end

struct Dog
end

impl Speak for Dog
  def speak -> String = "woof"
end

def main
end
```

See spec §3.5.
