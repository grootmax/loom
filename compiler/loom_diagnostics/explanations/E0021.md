# E0021: Invalid `\x` escape

You wrote a hexadecimal escape `\x` without two valid hex digits, or specified a non-ASCII code point (`\x80`–`\xFF`) in a standard string or character literal.

In standard strings and character literals, `\xHH` escapes are restricted to ASCII values (0x00–0x7F). Non-ASCII byte values (0x80–0xFF) are permitted only inside byte strings `b"…"`.

## Example

```loom
def main()
  s = "\x80"
end
```

## How to fix it

Use `\u{…}` for Unicode code points in standard strings, or use byte strings `b"…"` for raw bytes.

```loom
def main()
  s = "\x7f"
end
```

See spec §2.7.5.
