# E0210: Binding declared again in the same function

You declared a variable binding with `var` using a name that was already declared in the same function scope.

Loom does not allow shadowing variable bindings in the same scope or redeclaring variable names with `var`.

## Example

```loom
def main
  var x = 1
  var x = 2
end
```

## How to fix it

Reassign the existing variable or use a different name for the new binding.

```loom
def main
  var x = 1
  x = 2
end
```

See spec §4.1.
