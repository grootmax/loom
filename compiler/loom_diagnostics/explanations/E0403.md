# E0403: Name bound twice in one pattern

You bound the same variable name more than once within a single pattern.

Each variable name in a pattern must be unique to avoid binding ambiguity.

## Example

```loom
def main
  pair = (1, 2)
  case pair
    in (x, x)
      puts(x)
  end
end
```

## How to fix it

Use distinct variable names for each bound element in the pattern.

```loom
def main
  pair = (1, 2)
  case pair
    in (x, y)
      puts(x + y)
  end
end
```

See spec §9.1.
