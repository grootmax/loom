# E0019: Unknown escape sequence

You used an unrecognized escape sequence in a character or string literal.

Loom permits only specified escape sequences: `\n`, `\r`, `\t`, `\0`, `\\`, `\"`, `\'`, `\#`, `\xHH`, and `\u{H…}`. Other escaped characters (such as `\a` or `\c`) are invalid.

## Example

```loom
def main()
  s = "hello \a"
end
```

## How to fix it

Use a supported escape sequence or remove the backslash.

```loom
def main()
  s = "hello \n"
end
```

See spec §2.7.5.
