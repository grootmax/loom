# E0107: Positional argument after a named argument

In a function or method call, you placed a positional argument after a named (keyword) argument.

Loom requires all positional arguments to appear before any named arguments (`param: value`) in call argument lists.

## Example

```loom
def add(x: Int, y: Int) -> Int = x + y

def main
  add(x: 1, 2)
end
```

## How to fix it

Place positional arguments before named arguments, or pass all arguments by name.

```loom
def add(x: Int, y: Int) -> Int = x + y

def main
  add(1, y: 2)
end
```

See spec §3.1.
