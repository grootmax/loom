# E0405: Invalid range pattern

You specified a range pattern on a type that does not support range patterns, or used invalid bounds.

Range patterns `start..end` require integer or character bounds.

## Example

```loom
def main
  val = "hello"
  case val
    in "a".."z"
      puts(1)
    else
      puts(0)
  end
end
```

## How to fix it

Use range patterns with integer or character bounds.

```loom
def main
  val = 5
  case val
    in 1..10
      puts(1)
    else
      puts(0)
  end
end
```

See spec §9.1.
