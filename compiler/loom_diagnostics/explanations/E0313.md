# E0313: `?` used on a value or in a function that does not support it

You used the try operator `?` on a value that is not an `Option` or `Result`, or inside a function whose return type cannot propagate errors.

The `?` operator unwraps `Some` or `Ok` values, and early-returns `None` or `Err` if the value represents an error/absence.

## Example

```loom
def main
  x = 42?
end
```

## How to fix it

Use `?` on `Option` or `Result` values inside functions returning an `Option` or `Result`.

```loom
def helper -> Option[Int]
  val: Option[Int] = Option.Some(42)
  x = val?
  Option.Some(x)
end

def main
end
```

See spec §10.3.
