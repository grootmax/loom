# E0111: Two statements on one line

You placed two statements on a single line without a line break.

Loom does not use semicolons, and statements end at line breaks. Multiple statements on the same line are not permitted.

## Example

```loom
def main()
  x = 1 y = 2
end
```

## How to fix it

Place each statement on its own line.

```loom
def main()
  x = 1
  y = 2
end
```

See spec §2.3.
