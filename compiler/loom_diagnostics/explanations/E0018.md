# E0018: Unterminated string literal

A string literal was started with double quotes `"` but reached the end of the file without a closing double quote.

Every string literal must be terminated with a matching double quote `"`.

## Example

```loom
def main()
  s = "hello
```

## How to fix it

Close the string literal with a double quote `"`.

```loom
def main()
  s = "hello"
end
```

See spec §2.7.4.
