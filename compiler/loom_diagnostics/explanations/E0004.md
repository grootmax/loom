# E0004: Non-ASCII whitespace character

You wrote a non-ASCII whitespace character (such as U+00A0 NO-BREAK SPACE) outside of a string literal or comment.

Loom permits only ASCII space (`U+0020`) and ASCII tab (`U+0009`) as syntactic whitespace. Non-ASCII whitespace characters look visually identical to spaces but can lead to confusing parser errors.

## Example

```loom
def main()
  x = 10
end
```

## How to fix it

Replace the non-ASCII whitespace character with a standard ASCII space or tab.

```loom
def main()
  x = 10
end
```

See spec §2.2.2.
