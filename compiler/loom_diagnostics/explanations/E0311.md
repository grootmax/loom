# E0311: Operator not supported for these operand types

You applied a binary or unary operator to operands of types that do not support it.

Operators require operand types that define the operation (for example, numbers for arithmetic operators).

## Example

```loom
def main
  x = true * false
end
```

## How to fix it

Use operands of compatible types that support the operator.

```loom
def main
  x = 1 + 2
end
```

See spec §7.5.
