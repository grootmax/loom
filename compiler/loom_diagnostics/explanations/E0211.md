# E0211: Missing or invalid `main` function

Your program lacks a valid `main` entry point function or `main` has an invalid signature.

Every executable Loom program must define a top-level `main` function taking no parameters.

## Example

```loom
def run
  puts("hello")
end
```

## How to fix it

Define a `def main` function as the entry point of your program.

```loom
def main
  puts("hello")
end
```

See spec §14.1.
