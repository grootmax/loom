# E0404: Pattern does not fit the matched type

You used a pattern whose structure or type does not match the type of the expression being matched.

Patterns must match the type of the target value (for example, matching a tuple pattern `(a, b)` against a scalar integer expression is invalid).

## Example

```loom
def main
  val: Int = 42
  case val
    in (a, b)
      puts(a)
    else
      puts(0)
  end
end
```

## How to fix it

Use a pattern that matches the structure and type of the expression.

```loom
def main
  val = (1, 2)
  case val
    in (a, b)
      puts(a)
    else
      puts(0)
  end
end
```

See spec §9.1.
