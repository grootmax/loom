# E0010: Misplaced `_` in a numeric literal

You placed an underscore `_` in an invalid position within a numeric literal.

In Loom, underscores serve as visual digit separators and may appear only strictly *between* two digits (such as `1_000` or `0x1F_2A`). Underscores cannot appear at the beginning, at the end, consecutively (`1__0`), or immediately following a radix prefix (`0x_10`).

## Example

```loom
def main
  x = 1__000
end
```

## How to fix it

Place single underscores strictly between digits.

```loom
def main
  x = 1_000
end
```

See spec §2.7.1.
