# E0113: Glob imports are not supported (`use a.*`)

You attempted to use a wildcard or glob import like `use module.*`.

Loom does not support glob imports (`.*`). Requiring explicit import lists (`use module.{item1, item2}`) prevents namespace pollution, avoids name collisions, and keeps module dependencies explicit.

## Example

```loom
use std.math.*
```

## How to fix it

Import specific items explicitly using brace lists or module paths.

```loom
use std.math.{sin, cos}
```

See spec §3.7.
