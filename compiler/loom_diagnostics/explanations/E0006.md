# E0006: `;` is not used in Loom

You wrote a semicolon `;`. Semicolons are not used in Loom.

Statements in Loom end automatically at line breaks (unless extended by continuation rules). Semicolons are not recognized tokens.

## Example

```loom
def main
  x = 1;
end
```

## How to fix it

Remove the semicolon and use a line break to terminate the statement.

```loom
def main
  x = 1
end
```

See spec §2.3.4.

Coming from Rust/C/C++: Remove semicolons at the end of lines; line breaks separate statements in Loom.
