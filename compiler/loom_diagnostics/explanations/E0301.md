# E0301: Wrong number of arguments, or a missing argument

You called a function or method with a different number of arguments than its definition declares.

Function calls in Loom must supply arguments matching the declared parameter count.

## Example

```loom
def add(a: Int, b: Int) -> Int
  a + b
end

def main
  add(1)
end
```

## How to fix it

Pass the required number of arguments in the call.

```loom
def add(a: Int, b: Int) -> Int
  a + b
end

def main
  add(1, 2)
end
```

See spec §3.1.
