# E0008: `&&` or `||` is not an operator

You used `&&` or `||` as a logical operator. In Loom, `&&` and `||` are not logical operators.

Loom uses the keywords `and` and `or` for logical AND and OR expressions. Keyword operators read clearly and keep control flow expressions clean and readable.

## Example

```loom
def main()
  if true && false
    puts "yes"
  end
end
```

## How to fix it

Use `and` instead of `&&`, and `or` instead of `||`.

```loom
def main()
  if true and false
    puts "yes"
  end
end
```

See spec §2.8.4.

Coming from Rust/C/C++: Use `and` and `or` for boolean logic. Note that `{ || 42 }` remains valid syntax for an empty closure parameter list.
