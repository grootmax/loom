# E0104: Comparison operators cannot be chained

You chained comparison operators like `a < b < c`. In Loom, comparison operators are non-associative and cannot be chained directly.

Directly chaining comparisons can cause confusion regarding evaluation order and semantics across different languages. In Loom, multiple comparisons must be combined explicitly with `and`.

## Example

```loom
def main
  if 1 < 2 < 3
    puts "yes"
  end
end
```

## How to fix it

Split the comparison expression into separate comparisons connected with `and`.

```loom
def main
  if 1 < 2 and 2 < 3
    puts "yes"
  end
end
```

See spec §7.5.
