# E0201: Unknown variant or unqualified variant without an enum type

You referenced an enum variant that does not exist or used shorthand variant syntax where the enum type could not be inferred.

When using shorthand variant syntax like `.Variant`, Loom must be able to infer the expected enum type from the surrounding context. Alternatively, specify the type explicitly using `Enum.Variant`.

## Example

```loom
def main
  val: Option[Int] = DoesNotExist
end
```

## How to fix it

Use a known variant with explicit qualification or appropriate type context.

```loom
def main
  val: Option[Int] = Some(42)
end
```

See spec §3.3.
