# E0110: `else if` is written `elsif`

You wrote `else if` in a conditional expression. Loom uses the keyword `elsif`.

Writing `else if` is a syntax error in Loom. Using `elsif` keeps conditional branch keywords single tokens and avoids nested block parsing ambiguity.

## Example

```loom
def main()
  if false
    puts "a"
  else if true
    puts "b"
  end
end
```

## How to fix it

Replace `else if` with `elsif`.

```loom
def main()
  if false
    puts "a"
  elsif true
    puts "b"
  end
end
```

See spec §7.6.

Coming from Ruby/C/Rust: Use `elsif` instead of `else if`.
