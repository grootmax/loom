# E0024: Closing `"""` not on its own line

You wrote string content on the same line as the closing triple quotes `"""`.

The closing delimiter `"""` of a multiline string literal must appear on its own line, preceded only by whitespace. That whitespace determines the string's indentation prefix.

## Example

```loom
def main()
  s = """
  hello world"""
end
```

## How to fix it

Place the closing `"""` on its own line.

```loom
def main()
  s = """
  hello world
  """
end
```

See spec §2.7.4.
