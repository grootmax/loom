# E0105: Range operators cannot be chained (`a..b..c`)

You chained range operators like `1..5..10`. In Loom, range operators `..` and `..=` are non-associative.

Range operators construct discrete range objects and cannot be directly chained together in a single expression.

## Example

```loom
def main()
  r = 1..5..10
end
```

## How to fix it

Use parentheses or separate variable bindings to disambiguate range expressions.

```loom
def main()
  r = (1..5)
end
```

See spec §7.5.
