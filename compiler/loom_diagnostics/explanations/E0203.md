# E0203: Assignment to an immutable binding

You tried to reassign a value to an immutable variable binding.

In Loom, variable bindings are immutable by default. To allow reassigning a new value, declare the variable with `var`.

## Example

```loom
def main
  x = 10
  x = 20
end
```

## How to fix it

Declare the variable with `var` if you intend to reassign it.

```loom
def main
  var x = 10
  x = 20
end
```

See spec §4.1.
