# E0314: `break` with a value outside `loop`

You passed a return value to `break` inside a `while` or `for` loop.

In Loom, only infinite `loop` blocks can evaluate to a value when broken with `break value`. `while` and `for` loops do not yield values from `break`.

## Example

```loom
def main
  while true
    break 42
  end
end
```

## How to fix it

Use `loop` if you want the loop expression to return a value on `break`.

```loom
def main
  loop do
    break 42
  end
end
```

See spec §7.8.
