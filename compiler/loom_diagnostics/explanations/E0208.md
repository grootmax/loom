# E0208: `break` or `next` outside a loop

You used `break` or `next` outside of a loop construct.

Loop control statements `break` and `next` are only valid directly inside loop bodies (such as `loop`, `while`, or `for`).

## Example

```loom
def main
  break
end
```

## How to fix it

Use `break` or `next` only within a loop.

```loom
def main
  loop do
    break
  end
end
```

See spec §7.8.
