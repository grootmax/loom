# E0282: Type annotations needed

The compiler could not infer the type of an expression or variable binding because insufficient type information was available.

When type inference cannot unambiguously determine a type (for example, when instantiating a generic type without context), an explicit type annotation is required.

## Example

```loom
def main
  x = Option.None
end
```

## How to fix it

Provide an explicit type annotation on the variable binding or expression.

```loom
def main
  x: Option[Int] = Option.None
end
```

See spec §6.2.
