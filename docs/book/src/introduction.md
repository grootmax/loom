# Introduction

*The Loom Book* teaches Loom from scratch. It is written for people who have
programmed before in any language.

> Loom is pre-alpha. Nothing in this book runs yet; chapters are written as the features
> they describe are implemented (see the [roadmap](https://github.com/grootmax/loom/blob/main/docs/roadmap.md)).

Loom reads like Ruby, is safe and fast like Rust, and does concurrency like Go:

```loom
def main
  puts "Hello, world!"
end
```
