# Code of Conduct

The Loom project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full and without modification. It applies in every project
space — repositories, issues, discussions, chat and events — and when representing the
project in public.

## In short

Be kind, be patient, assume good faith, and critique ideas rather than people. Harassment,
personal attacks, and discriminatory language are not tolerated.

## Reporting

Report incidents privately to the project maintainers through GitHub's private
reporting to the repository owner (@grootmax) until a dedicated conduct address exists.
Reports are handled confidentially. Enforcement follows the Contributor Covenant's
Enforcement Guidelines (correction, warning, temporary ban, permanent ban).

Responsibility for enforcement sits with the governance body described in
[GOVERNANCE.md](GOVERNANCE.md).
